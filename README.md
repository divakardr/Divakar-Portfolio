# Divakar DR — Developer Portfolio

A responsive, single-page portfolio website with:
- Dark/light theme toggle
- Mobile navigation
- Smooth scroll and reveal animations
- About, skills, projects, education/experience, and contact sections
- GitHub and LinkedIn links

## Before publishing
1. Add your real portrait photo to `assets/` and name it `profile.jpg`.
2. Check every project description and update it to match the current implementation.
3. Add project repository/demo links when available.
4. Confirm the education dates and contact email.

## Preview locally
Double-click `index.html`, or open this folder in VS Code and use the Live Server extension.

## Publish free with GitHub Pages
1. Create a new public GitHub repository, for example `divakar-portfolio`.
2. Upload `index.html`, the `assets` folder, and this README.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then click **Save**.
6. Wait a minute or two. GitHub will show your live website URL.

You can also deploy the folder using Netlify Drop or Vercel static deployment.
